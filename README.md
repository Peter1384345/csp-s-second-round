# CSP-S 2026 第二轮 · 在线刷题与实时评测

面向 **CSP-S（CCF CSP 提高组）2026 第二轮（机试）** 的高效备考工具：单文件网页应用，支持**在线答题 + 实时评测**，考点全覆盖，开箱即用。

- **考试信息**：机试，4 题 × 100 分 = 400 分，官方时间 **2026-10-31 14:30–18:30**（约 4 小时，以 CCF 通知为准）。
- **部署方式**：纯静态单文件，可本地双击打开，或托管于 GitHub Pages。

---

## ✨ 功能

| 模块 | 说明 |
|------|------|
| 📚 **题库** | 16 道原创题，按 T1–T4 分档，覆盖模拟、前缀和、二分、贪心、单调栈、并查集/MST、高精度、LIS/背包 DP、Dijkstra、树的直径、拓扑 DP、矩阵快速幂、KMP、BFS、树状数组等考点 |
| ⏱ **在线答题** | 内置 CodeMirror C++ 编辑器，支持语法高亮、Tab 缩进、代码本地保存 |
| 🔍 **实时评测** | 提交后调用 **Wandbox** 公共编译服务逐条运行测试数据，实时反馈 AC / WA / RE / CE / TLE，按测试点给分（可拿部分分），每题 100 分 |
| 🏆 **模拟赛** | 3 套模拟卷（每套 4 题对应 T1–T4、总分 400），限时 240 分钟，顶部计时条，取每题最高分计总 |
| 🧭 **知识图谱** | 10 大板块、58 个考点自评（掌握 / 待巩固），掌握度进度条，查漏补缺 |
| 📊 **我的记录** | 提交历史、错题本（部分分自动收录）、得分统计，全部保存在浏览器 localStorage |

## 🚀 快速开始

### 方式一：直接打开
下载 `index.html`，用浏览器打开即可使用（需联网，用于加载 CodeMirror 与调用评测 API）。

### 方式二：GitHub Pages 托管
```bash
git clone https://github.com/Peter1384345/csp-s-second-round.git
# 将 index.html 放到 gh-pages 分支或仓库根目录
# 在仓库 Settings → Pages 中选择分支并启用
```
启用后访问 `https://Peter1384345.github.io/csp-s-second-round/`。

## ⚙️ 关于实时评测

GitHub Pages 只能托管静态页面，无法在后端编译 C++，因此本站通过浏览器调用 **Wandbox**（`https://wandbox.org/api/compile.json`，公共、免密钥、支持 CORS）实时编译并运行你的代码，再用题目自带的隐藏测试数据判定结果。

- 编译环境：gcc 13.2.0（C++17），支持 `#include <bits/stdc++.h>`。
- 判定规则：与官方一致，**按通过测试数据比例给分**，单个测试点可通过即得分。
- 注意：评测结果以官方评测环境为准；本站用于高效备考练习，请勿用于违反考试纪律的场景。

## 📖 题库与数据

题目位于 `solutions/gen_problems.py` 与 `solutions/validate.py`：每题都配有**独立编写的期望输出**（非参考程序自身输出）用于交叉验证，参考 AC 解法在 `solutions/*.cpp`。所有题目已用本地 g++ 与 Python 双重验证，可复现。

## 🗂 目录结构

```

  gen_problems.py   生成题库 JSON
  problems_data.js  生成的题库数据
README.md
LICENSE
```
